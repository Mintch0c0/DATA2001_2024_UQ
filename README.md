# DATA2001 – Foundations of Data Science

This repository contains my coursework for **DATA2001: Foundations of Data Science** at **The University of Queensland (2024)**.

DATA2001 introduces the foundations of data science and focuses on working with real-world data to answer questions, identify patterns, communicate findings, and make data-driven predictions. Throughout the course, I worked with different datasets and applied data processing, analysis, visualisation, and modelling techniques.

## Assignments

The coursework is organised into three main parts:

### Hindsight

Focused on using historical data to understand **what has happened in the past**.

This involved working with datasets, cleaning and preparing data, exploring variables, and using data analysis and visualisation techniques to identify patterns and trends.

### Insight

Focused on understanding **what the data can tell us**.

This assignment involved deeper exploration of data, identifying relationships between variables, creating visualisations, and interpreting the results to communicate meaningful findings.

### Foresight

Focused on using data to explore **what may happen in the future**.

This involved applying predictive and data modelling techniques to use existing data to make predictions and evaluate the results.

## Skills Practised

Through these assignments, I gained experience with:

- Data cleaning and preprocessing
- Exploratory data analysis
- Data visualisation
- Statistical analysis
- Working with real-world datasets
- Interpreting and communicating data
- Predictive modelling
- Writing data-driven conclusions
